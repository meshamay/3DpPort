# Images Folder

Place your 3D model thumbnail images here.

## Expected Images:
- `cube.jpg` - Thumbnail for Futuristic Cube
- `sphere.jpg` - Thumbnail for Abstract Sphere
- `torus.jpg` - Thumbnail for Torus Knot
- `dodecahedron.jpg` - Thumbnail for Dodecahedron
- `cylinder.jpg` - Thumbnail for Cylinder Design
- `cone.jpg` - Thumbnail for Cone Structure

## Image Guidelines:
- **Format:** JPG, PNG, or WebP
- **Dimensions:** 600x400px or similar aspect ratio (3:2)
- **Size:** Keep under 200KB for optimal loading
- **Quality:** High enough to showcase your work clearly

## Adding Images:
1. Add your image files to this folder
2. The gallery will automatically display them
3. If an image is missing, a placeholder icon will show instead

You can also add more images and reference them in the `portfolioItems` array in `script.js`.
